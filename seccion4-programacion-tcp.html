Programación de Servidor y Cliente TCP

Servidor: socket() → bind() → listen() → accept() → recv() → send() → close().

Cliente: socket() → connect() → encode() → send() → recv() → decode() → close().

El servidor debe iniciarse primero: debe estar escuchando antes de que el cliente intente conectarse.
